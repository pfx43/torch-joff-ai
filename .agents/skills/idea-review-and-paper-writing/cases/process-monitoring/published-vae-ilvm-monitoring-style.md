# Published style exemplar: VAE-ILVM process monitoring

- Corpus ID: P05
- Paper: *VAE-Based Interpretable Latent Variable Model for Process Monitoring*
- Case role: published-style exemplar
- Task group: process monitoring, structural detectability, and threshold design
- Positive-use tier: primary question-led Introduction and theory source

## Architecture worth retaining

The Introduction contrasts interpretable shallow latent-variable models with
expressive but opaque deep models, states a structural detectability requirement,
raises focused questions, and derives matched contributions. Threshold learning
is separated as an independent task with its own motivation and theory.

## Narrative pattern

`interpretable shallow objective -> deep expressiveness -> black-box structural
gap -> detectability requirements -> focused questions -> Taylor-guided design
-> threshold sample issue -> martingale inequality -> matched simulations`

## Do not imitate

Do not describe every activation-function choice as interpretable, infer
detectability from empirical separation alone, or use `significantly` without a
defined statistical or practical comparison.
