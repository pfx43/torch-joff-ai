# Model-structure-diagram category case

Use this category for overall model, forward modules, local components, losses,
constraints, and complete input/output interfaces. Analyze reading direction,
titled major frames, contained detail, forward-to-loss relation, task-output
placement, repeated layers, and scientifically justified local zoom-ins.

Prefer figures whose model remains understandable without long text and whose
arrows connect defined shapes. Do not copy the source model, labels, symbols,
or distinctive complete layout.

Record each reference in `references.md`. Put only authorized source images in
`images/` and use the reference ID in the filename.
