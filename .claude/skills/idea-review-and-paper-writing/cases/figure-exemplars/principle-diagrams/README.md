# Principle-diagram category case

Use this category for mechanism, geometry, transformation, separation, state
evolution, energy, probability, boundary, or other scientific-principle
figures. No universal layout applies, so every active use requires a current
related-literature search.

Analyze how references convert equations or abstract relations into spatial,
temporal, geometric, or information-flow explanations. Preserve the current
paper's own scientific topology. Do not infer that a source paper's relation,
guarantee, or physical meaning applies to the active manuscript.

Record each reference in `references.md`. Put only authorized source images in
`images/` and use the reference ID in the filename.
