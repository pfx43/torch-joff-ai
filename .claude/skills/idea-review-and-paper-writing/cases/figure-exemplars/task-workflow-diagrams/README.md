# Task-workflow-diagram category case

Use this category for data acquisition/preprocessing, offline modeling, online
monitoring/use, task decisions, and other operational steps. Analyze titled
step frames, local one-way chains, offline/online separation, cross-step
connectors, handoff objects, and final task outputs.

Reject workflows that substitute business-process icons for scientific
objects, conceal information availability, or use ambiguous cyclic arrows.

Record each reference in `references.md`. Put only authorized source images in
`images/` and use the reference ID in the filename.
