# Published-paper style exemplar library

This directory provides cross-case style synthesis from the user's published-
paper corpus without turning examples into a second rule system. Concrete
source excerpts live in one-paper, task-grouped files under `../../cases/`.

## Authority and boundary

- Cross-manuscript requirements remain authoritative in
  `../living-user-rules.md`.
- The repeated Stage 3 checks remain authoritative in
  `../manuscript-writing-loop.md`.
- Files in this directory provide source-tagged patterns and micro-examples.
  They are evidence of an established writing tendency, not authority for a
  technical claim, assumption, theorem, novelty judgment, citation, or target-
  journal requirement.
- Reuse the relation and rhetorical structure; do not paste whole source
  paragraphs. Verify all borrowed terminology against the active research
  community, and cite the primary technical source rather than this library.
- The target journal's instructions and the current manuscript's information
  boundary override a corpus habit.

## Reading route

Read only what the current writing action needs:

1. Read `corpus-index.md` when selecting the task-matched one-paper case or
   checking provenance. Then read only that case.

2. Read `architecture-and-narrative.md` when planning chapters, paragraphs,
   macro-to-micro explanation, method decomposition, or Stage 4 experiment
   narration.

3. Read `sentence-and-transition-exemplars.md` only for cross-case sentence-form,
   transition, and modifier synthesis; concrete excerpts remain in the selected
   case.

## Use loop

For each paragraph:

1. State its single theme and purpose before selecting a style pattern.

2. Identify the actual relation to the previous paragraph: continuation,
   contrast, cause, purpose, refinement, derivation, consequence, evidence,
   limitation, or transition.

3. Select at most the sentence forms needed to express that relation. Do not
   add a connector, passive construction, clause, or modifier merely because it
   appears in the exemplar bank.

4. Adapt the pattern to the current technical objects and define every term and
   symbol through the normal notation workflow.

5. Execute the relevant Stage 3 W1–W10 audits and update the paragraph purpose/progression
   map. Corpus resemblance never substitutes for a semantic audit.

## Maintenance

When adding papers or examples, record the source ID, title, venue/year,
language, PDF page or section, exact rhetorical function, and selection reason.
Keep exact quotations short. If a sentence is useful only after grammatical or
logical repair, label the repaired version as an adaptation rather than an
exact excerpt.
