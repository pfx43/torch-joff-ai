# Icon registry

One row represents one downloaded source asset or one normalized derivative.
Do not add a local icon file without completing its row.

| Registry ID | Local path | Source site | Asset/library/author ID | Exact asset URL | Access date | File format | License/permission | Commercial publication allowed | Attribution text/location | Source or derivative | Parent registry ID | Scientific meaning | Status |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |  |  | BLOCKED |

Allowed status values are `APPROVED`, `BLOCKED`, and `RETIRED`. `APPROVED`
requires a saved source/permission record and a license compatible with the
target publication. A missing or ambiguous license is `BLOCKED`, not assumed
permission.
