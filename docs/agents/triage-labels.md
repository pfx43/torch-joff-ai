# 分诊标签

技能以五个规范化的分诊角色描述状态。此文件将这些角色映射到本仓库事项追踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 追踪器中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此事项 |
| `needs-info` | `needs-info` | 等待报告者补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 AFK 代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某一角色时（例如“应用 AFK 就绪分诊标签”），使用表中对应的标签字符串。

如需改用现有词汇，请修改表格右侧的标签列。
