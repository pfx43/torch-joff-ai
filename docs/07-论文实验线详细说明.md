更新日期：2026-07-30

## 0. 初次出现的缩写与统计量

- episode（完整运行片段）：从一次已声明的开始状态连续运行到结束、校准时不可拆散的一条序列；
- RMSE（root mean square error，均方根误差）：衡量预测值与真实值之间的平均误差幅度；
- FAR（false alarm rate，误报率）：本文默认指“至少出现一次误报的正常 episode 占比”；
- MDR（missed detection rate，漏检率）：真实故障 episode 中未被冻结规则检出的占比；
- PCA（principal component analysis，主成分分析）：经典线性降维与统计监测基线；
- Hotelling $T^2$：PCA 主子空间内的标准化变化统计量；
- SPE/Q（squared prediction error，平方预测误差）：PCA 未解释残差能量的统计量；
- L1 分数：把窗口内残差各分量的绝对值相加得到的分数。

更完整的机制直觉见《[论文代码实施计划](./06-论文代码实施计划.md)》第 2 节。

## 1. 这条实验线到底要回答什么

最新版实验线不再以“认证 white-space 后滤波能否把物理三类故障唯一分开”为中心。它要回答三个按依赖顺序排列的问题：

1. 只用正常数据训练的严格因果 Attention–Koopman–T–S 模型，能否在不让新测量污染正常参考的条件下稳定地产生多步参考和残差？

2. `u/y/z` 三组模型坐标基扰动能否形成可重放、可区分的标准化残差响应，并支持短窗口和长窗口的多尺度监测？

3. 当观测模式不能唯一对应某一组时，方法能否诚实返回兼容集合，而不是把模型坐标强行解释成物理故障类别？

实验的目标不是尽快得到一个最高准确率，而是建立合法的数据流程、可追溯产物和与主张一一对应的证据。

## 3. 数据怎样流动

### 3.1 五个正常阶段

| 阶段 | 允许做什么 | 禁止做什么 |
|---|---|---|
| 正常训练 | 训练编码器、Koopman–T–S 模型、结构化响应损失，选择 checkpoint | 看故障结果；拟合最终阈值；报告冻结测试性能 |
| 正常估计 | 拟合工况条件标准化、正常 forcing bound、basis 响应统计和支持范围 | 改训练 checkpoint；使用检测或归因校准结果反调结构 |
| 检测校准 | 对完整正常 episode 计算多尺度最大分数，冻结检测阈值 | 重新拟合标准化；改变窗口族；参与归因校准 |
| 归因校准 | 冻结模式兼容容差和唯一性 margin | 复用检测校准 episode；读取故障标签 |
| 冻结正常测试 | 只评价正常误报、unsupported 和兼容集合行为 | 再训练、再拟合或选择参数 |

五段之间必须保留隔离带。隔离带长度由历史窗口、预测视野、残差窗口和 episode 边界共同决定，不能只留一个任意样本。

### 3.2 独立冻结故障测试

冻结故障测试不属于正常第五段。只有以下对象全部冻结后，才允许一次性读取：

- 模型和 checkpoint；
- reference 和锚点策略；
- Jacobian bound 和可靠视野；
- basis 组、坐标、幅值和插入时刻；
- 工况条件标准化；
- 窗口族和 detection threshold；
- pattern library、兼容容差和唯一性 margin；
- 指标、图表 schema、代码版本和配置 hash。

### 3.3 为什么检测与归因校准必须分开

检测校准回答“正常 episode 是否会出现至少一次误报”。归因校准回答“在已冻结检测规则下，如果要求判断 `u/y/z` 模式，会多大程度把正常残差误认为某一组”。

两者使用同一批 episode 会让第二个阈值间接看到第一个选择过程，破坏风险分账，因此必须互斥。

## 4. 从原始序列到最终决定

本节只维护实验运行顺序；对象字段、接口语义和失败条件只以 06 为准。一条 episode 的 V2
数据流是：

1. 从严格过去历史编码锚点状态；

2. 延迟确认锚点后启动测量解耦正常参考；

3. 数据支路继续读取真实测量，参考支路只用记录命令、外生量和模型预测递推；

4. 按统一 start index 形成潜变量和输出残差；

5. 用正常估计段冻结的工况统计标准化残差；

6. 在预声明的有限窗口族上计算 L1 分数；

7. 对窗口族取时刻最大值；

8. 用 detection-calibration episode maxima 冻结阈值并判断报警；

9. 报警后把标准化残差与 `u/y/z` 响应模式比较；

10. 输出唯一模型坐标组、兼容集合或 `unsupported`。

其中第 9–10 步不是物理故障定位。没有额外物理映射时，只能解释为“观测更接近哪类模型坐标扰动响应”。

## 5. 实验分层

实验分为三个证据层，不能混写。

### 5.1 第一层：正常建模

目标是判断基础模型是否值得进入监测链。

主要检查：

- 分视野预测 RMSE（均方根误差）；
- 当前和未来真实测量是否泄漏进自由参考；
- T–S 规则使用率；
- 潜变量标准差；
- 单规则退化；
- 完整 Jacobian 与 autograd、有限差分的一致性；
- 不同 horizon 的误差增长。

失败时优先缩短视野、减少规则数或回退单一 Koopman，而不是继续叠加监测模块。

### 5.2 第二层：最新版机制

目标是验证每个新增机制是否产生它声称的可计算对象。

主要检查：

- Jacobian 无穷范数上界是否覆盖实际完整 Jacobian；
- 递推误差界是否按 reference age 单调传播；
- 可靠参考视野是否对容差和 bound 单调；
- `u/y/z` 响应是否可重放；
- 小扰动幅值下缩放灵敏度是否稳定；
- 组内模式离散度与组间距离；
- 条件标准化是否覆盖冻结工况；
- 多尺度分数是否包含全部窗口；
- episode threshold 是否满足有限样本分辨率；
- 兼容集合是否对容差扩张保持单调。

这些结果可以使用 synthetic 或正常数据，但不能写成故障检测性能。

### 5.3 第三层：冻结故障评价

目标是评价完整冻结方法在从未用于选择的故障 episode 上的表现。

主要检查：

- episode 级 FAR（误报率）；
- MDR（漏检率）；
- 检测延迟；
- 每个窗口的报警贡献；
- 唯一组、兼容集合和 `unsupported` 频率；
- 兼容集合大小；
- 唯一输出率；
- 唯一输出条件正确率；
- 运行时间、峰值内存和每样本在线耗时。

该层必须等 CSTR 数据许可和 V2 协议共同冻结后才能执行。

## 6. 公平基线

所有基线使用相同的五阶段正常数据预算、隔离带、冻结故障范围、随机种子政策和逐时刻产物粒度。

| 基线 | 作用 | 主要分数 | 公平性要求 |
|---|---|---|---|
| PCA `T^2`/SPE | 经典线性正常统计监控 | `T^2`、SPE/Q | 主成分数只用正常数据选择 |
| Reconstruction model | 静态非线性正常流形 | 重构误差 | 结构和 checkpoint 不用故障结果选择 |
| One-step predictor | 一步动态预测 | 一步预测误差 | 使用相同控制、外生量和正常预算 |
| Measurement-driven Koopman | 持续使用新测量更新模型状态 | Koopman 预测或重构残差 | 明确它不是测量解耦参考 |
| Proposed V2 | 测量解耦参考与结构化 basis 响应 | 多尺度标准化残差 | 全部 V2 对象在故障访问前冻结 |

若某一方法需要故障标签、已知物理故障方向或监督分类，应作为“有监督或有先验参考”单独报告，不能混入 normal-only 排名。

## 7. V2 消融

正式消融只保留能回答一个明确机制问题的六项。

| 编号 | 消融 | 要回答的问题 | 主要观察 |
|---|---|---|---|
| V2-A1 | 测量回注参考代替测量解耦参考 | 新测量持续修正是否造成异常泄漏或残差抵消 | 参考差异、正常误报、故障延迟 |
| V2-A2 | 单规则 Koopman 代替 T–S 模糊模型 | 多运行区域局部模型是否必要 | 分区域 RMSE、bound、正常覆盖 |
| V2-A3 | 移除结构化 basis 损失 | 响应灵敏度和组间分离是否来自该训练目标 | 灵敏度、组间距离、集合大小 |
| V2-A4 | 移除条件标准化，使用全局尺度 | 工况、命令变化和 reference age 条件化是否必要 | 不同区域 FAR、unsupported、尺度漂移 |
| V2-A5 | 单窗口代替多尺度窗口族 | 多尺度是否同时改善短故障与慢变化监测 | MDR、delay、窗口贡献 |
| V2-A6 | 强制 singleton，不允许兼容集合 | 强制唯一输出制造多少错误确定性 | 错误 singleton、唯一率、集合覆盖 |

消融不得执行全部 $2^6$ 组合。每项只改变一个声明机制，其他数据、训练预算和阈值流程保持一致。

## 8. 指标定义

### 8.1 正常建模指标

#### 分视野 RMSE

对每个预测视野分别计算输出预测均方根误差。不得只报告所有视野混合后的单个平均值，否则无法观察误差是否随展开迅速增长。

#### 规则使用率

统计每条 T–S 规则在样本和视野上的平均隶属度。规则使用率接近零表示规则可能失活，但不能仅凭均匀使用率判断模型有效。

#### 潜变量退化

报告锚点潜变量各维标准差及最小值。若若干维几乎恒定，应标记 latent collapse 风险。

### 8.2 最新机制指标

#### 上界覆盖率和松弛比

逐步检查：

`bound >= complete Jacobian infinity norm`

覆盖率必须为 100% 才能称为上界实现合同成立。另报告 `bound / actual` 的分布，用来判断上界是否过松；该比例不是理论正确性的替代。

#### 可靠参考视野

在冻结容差下，误差递推界连续不超过容差的最大步数。若第 1 步即超限，应返回 0，不得为了画图强行保留一个正视野。

#### 缩放灵敏度

对 basis 扰动前后残差差分取 L1 范数，再除以扰动幅值。必须报告幅值范围，避免把数值噪声或明显非线性区间混在一起。

#### 模式分离

分别报告组内距离和组间距离。若组间最小距离不大于组内变化和冻结容差之和，应允许兼容集合，不能宣称唯一分离。

#### 正常多尺度误报

在冻结正常测试上报告：

`出现至少一次报警的正常 episode 数 / 正常 episode 总数`

这属于 episode-level FAR，不是逐时刻误报比例，也不是无限期运行保证。

### 8.3 冻结故障指标

#### MDR

MDR 是漏检率：

`评价窗口内未满足持续报警规则的故障 episode 数 / 故障 episode 总数`

#### 检测延迟

从真实 onset 到第一次满足冻结持续报警规则的采样步数。未检测 episode 必须按 manifest 规定记为删失、缺失或窗口上限，不能写成 0。

#### 兼容集合大小

对每个合法决策时刻记录兼容组数。集合越小不自动表示更正确，还必须与覆盖和错误 singleton 一起报告。

#### 唯一输出率

`unique 决策数 / 全部受支持决策数`

#### 唯一输出条件正确率

只有在数据集提供了经审查的模型坐标组真值或额外映射时才能计算：

`正确 unique 数 / 全部 unique 数`

它不能冒充总体分类准确率。

## 9. 科研图总体规则

每张图在绘制前必须记录：

- 图的唯一目的；
- 支持的论文解释或主张；
- 数据属于 conceptual、synthetic、normal-only 还是 frozen fault；
- 输入产物和配置 hash；
- 生成脚本；
- 样本数和聚合方式；
- 不得从图中推导的结论；
- 预期一栏、双栏或页宽；
- 编辑源和导出格式。

统一使用 `summer-ocean-breeze`：

| 视觉角色 | 颜色 |
|---|---|
| 背景 | `#F1FAEE` |
| 主文字和主轮廓 | `#1D3557` |
| 次级结构和比较线 | `#457B9D` |
| 低强调填充和不确定带 | `#A8DADC` |
| 异常、超限或唯一重点 | `#E63946` |

图中不能只靠颜色编码。多组曲线还必须使用线型、marker、直接标签或分面。定量图保留绘图脚本和机器可读数据，优先导出矢量 PDF；同时生成便于检查的 PNG。

## 13. 每次运行必须保存什么

正式表图不能从终端手抄。每次 development 或 frozen 运行至少保存：

| 产物 | 用途 |
|---|---|
| resolved config、provenance、config hash | 确认最终实际配置 |

| 数据、split、gap、window、episode hash | 防止数据或窗口漂移 |
| fit access ledger | 审计每个拟合对象访问了哪个阶段 |
| checkpoint、训练历史、随机状态 | 重放正常模型 |
| start-index manifest 和 reference trace | 重放锚点、age 和索引 |
| Jacobian 与 bound trace | 重放传播界 |
| basis manifest 和 responses | 重放 `u/y/z` 模式 |
| fitted standardizer | 重放工况均值和尺度 |
| multiscale calibration | 重放窗口与 episode threshold |
| pattern library | 重放兼容集合 |
| 逐时刻结果 | 重算指标和时间曲线 |
| table/figure source manifest | 自动重建论文表图 |

## 15. 阶段验收方式

每个实验阶段按以下顺序验收：

1. 检查前置数据阶段和访问账本；

2. 运行对应公开测试和手算小例子；

## 16. 常见错误

| 错误 | 正确处理 |
|---|---|
| 把 `u/y/z` 写成执行器、传感器、过程故障 | 写成模型坐标扰动组；物理解释另需映射证据 |
| 把新测量写回正常参考 | 新测量只留在数据支路和残差侧 |
| 用故障结果挑窗口或 basis | 所有选择在正常阶段完成并冻结 |
| 把上界正则写成严格认证 | 分清结构硬约束、可实现上界、软正则和事后检查 |
| 只校准逐时刻分数 | 对预声明窗口族和完整 episode 取最大值 |
| 强制每次输出一个组 | 返回兼容集合或 `unsupported` |
| 只报告 unique 条件正确率 | 同时报告 unique 率和集合大小 |
| 用 synthetic 曲线填正式故障图 | 明确标注 synthetic，并把正式图保持 blocked |
| 继续把旧 P6/P7/P9 当最新版前置 | 只作为历史实现或未来可选路线 |
