## 1. 第一性原理诊断：老师的三点批评句句有病灶

### 1.1 后滤波器——被论证掉了，而不是被设计出来

现设计第 14 节的立场是"不需要独立后滤波器"：以命题 3（任何秩亏投影对未知故障必有盲向）为由，主张满秩条件白化 + 多尺度堆叠已完成后滤波器的全部合法目标。这个论证有两个实质漏洞：

1. 命题 3 只是一个**可采性约束**（排除针对任意未知故障的秩亏投影），不是"无事可做"的证明。堆叠残差有强时间结构——定理 1 给出精确分解 $e^z_{k\mid s}=\sum_j \Phi(k,j{+}1)(\nu^E_j+\delta^\chi_{j\mid s})$，其中锚点误差、上下文失配这些**正常侧结构扰动的到达子空间是低维、已知、在线可算的**。对已知扰动结构做解耦或衰减不需要任何故障先验——这正是经典 parity space 与 Ding 后滤波器的第一性原理。现设计对这些扰动只做范数球上界然后并进阈值，等于把本可滤掉的结构性扰动全部转嫁给阈值：既保守，又浪费了 T–S Koopman 模型自带的结构信息。

2. "满秩白化即后滤波器"回避了故障类间的灵敏度整形。三类故障的签名算子（第 2 节）在线可算，做匹配增强并不与命题 3 冲突——保留满秩全能支路、并联结构化匹配支路、对 max 统计量统一校准即可（与现有 $T^{\max}$ 的多尺度逻辑同构）。

结论：老师要的不是"解释为什么不用"，而是**用模型结构设计出有定理支撑的后滤波器**。这个要求合理，且现框架完全支撑得起。

### 1.2 动态阈值——输入实测值其实没有进入确定性部分

现设计 $\gamma^{\mathrm{dyn}}_k=\gamma^{\mathrm{det}}_k+\gamma^{\mathrm{cal}}$ 看似"确定性传播 + 随机校准"，逐项检查后：

1. $\gamma^{\mathrm{det}}_k=\|W_k\|_2\,\beta^R_k$，而半径递推 $\beta_{k+1}=L_k\beta_k+\bar\epsilon_k$ 是**标量球**：方向信息全部丢失（$\|W_k\|_2$ 取白化最坏方向），$\bar\epsilon_k$ 是按区域离线预估的**常数包络**。运行状态确实经 $L_k$ 与区域索引间接进入，但测得的 $u_k$ 瞬时幅值与方向、$\Delta u_k$ 的激励强度、模型失配随输入的缩放，都没有在线进入界——"随输入变化"只通过条件矩 $\mu_R(\zeta),\Sigma_R(\zeta)$ 的统计条件化间接体现，那不是残差动力学传播。

2. 后果：确定性部分要么松到没有约束力（球最坏方向 × 常数包络），要么由 conformal 分位实际承担全部工作。审稿人会直接判定这是"经验分位数 + 摆设的确定性偏移"——skill 规则也明确禁止把滚动分位数称作 Ding 意义的动态阈值。

3. 堆叠窗口的 $\Gamma^{\mathrm{det}}_{k,N}$ 用每步半径的根和方乘 $\|W^{\mathrm{stk}}\|_2$：同一锚点误差经 $\Phi$ 在窗口内强相关传播的**跨时刻结构被丢弃**，而 skill 规则明确要求 stacked bound 保留 cross-time propagation。

### 1.3 结构化隔离——两类是设计、一类是剩余，传感器层没有理论

1. 传感器层：屏蔽编码器与豁免检验都是经验设计 + 启发式判决（设计文档自己的标注如此），没有传感器故障的签名模型，判决没有可分性条件。

2. 执行器/过程分解：只有执行器有真正签名（输入响应矩阵）；过程故障被定义为"正交剩余"——**不是被设计出来的类**，任何未建模现象都会落进去。

3. 三类之间没有统一的结构化残差框架：没有关联矩阵（incidence structure），没有类间可分性定理（现有裕度 $\gamma_j$ 只覆盖执行器通道之间），传感器故障经控制器进入 $u$ 的闭环二次进入只靠"早期窗口"经验规则兜底。

## 2. 统一重构框架：一个对象、三组算子

三个突破点共享同一个数学对象——**评价窗内的堆叠受保护残差**。固定锚点 $t_0$、窗长 $N$，由定理 1（保留，精确恒等式）沿受保护轨迹线性化后：

$$
\mathbf e_{t_0,N}
=\underbrace{\bm G_{\mathrm{anc}}\tilde e_{t_0}+\bm G_{\chi}\bm\delta^{\chi}+\bm G_{m}\bm m}_{\text{正常侧结构扰动}}
+\underbrace{\bm G_{\nu}\bm\nu}_{\text{随机新息}}
+\underbrace{\bm F_{\mathrm a}\bm f^{\mathrm{act}}+\bm F_{\mathrm s}\bm f^{\mathrm{sen}}+\bm F_{\mathrm p}\bm f^{\mathrm{proc}}}_{\text{三类故障签名（LTV 线性化）}}
$$

其中（全部沿受保护支路装配、隶属度调度、JVP 在线可算、仅依赖正常数据训练的模型）：

- $\bm G_{\mathrm{anc}}$：锚点误差传播算子，堆叠的 $\Phi(t_0{+}l,t_0)$——整个窗内只张成 $m_z$ 维子空间（关键事实，后滤波器的解耦对象）；

- $\bm G_{\chi}$：上下文失配的 $\ell_h$ 阶时滞链算子（引理"上下文灵敏度"已给出其结构）；$\bm G_m$：模型失配注入算子（输入相关，第 4 节）；$\bm G_{\nu}$：新息的下块三角 Toeplitz 传播算子；

- $\bm F_{\mathrm a}$：$\Phi$ 加权 $B^u$ 下块三角算子（即已修正配对的 $B^{\mathrm{resp}}$，保留）；

- $\bm F_{\mathrm s}$：**新增**——传感器故障经编码器历史槽位的滞后签名算子（对 $\mathcal E_\vartheta$ 关于 $y$ 槽位做 JVP 得到）加上 $r^y$ 直通块；屏蔽编码器由此获得理论定位：掩码 $=$ 对该算子编码器介导路径的**零化器实现**；

- $\bm F_{\mathrm p}$：过程故障经状态通道的 Toeplitz 注入算子——过程类从"正交剩余"升级为有签名、有激励条件的**被设计的类**。

三个模块随即统一：**后滤波器**是对 $\mathbf e$ 的线性算子设计（零化/衰减 $\bm G$ 族 + 跨时刻白化 + $\bm F$ 族匹配支路）；**动态阈值**是对同一组 $\bm G$ 算子做方向保留、由输入实测值驱动的集合传播；**结构化隔离**是对 $\{\bm F_{\mathrm a},\bm F_{\mathrm s},\bm F_{\mathrm p}\}$ 的关联结构设计滤波器组加主角裕度可分性定理。这条主线本身就是论文 Sec. III 的叙事骨架，是对"核心内容"最直接的加强。

（符号说明：$\bm F$ 族取"故障签名"语义、与故障家族 $f$ 同基字符，$\bm G$ 族为临时记号；最终符号在 P3 的符号账本阶段统一定夺并做全稿冲突检查。）

## 3. 突破一：堆叠残差后滤波器设计

设计为三级复合 $\mathbf V=\{\text{支路库}\}\circ \bm W^{1/2}_{\mathrm{stk}}\circ \Pi^{\perp}_{\mathrm{anc}}$：

1. **结构扰动零化级** $\Pi^{\perp}_{\mathrm{anc}}$：左零化 $\mathrm{Range}(\bm G_{\mathrm{anc}})$（parity space 式投影）。代价只有 $m_z$ 维（窗口总维 $Nm_z$），收益是消掉现阈值中最保守的 $\beta^{\mathrm{lg}}$ 项；被零化掉的故障方向恰是与锚点误差传播不可分的方向——这不是损失而是诚实刻画（写成核空间刻画命题）。$\bm G_{\chi}$ 时滞链不整段零化（维数随 $\ell_h$ 增长），改 $H_\infty$ 式加权衰减，衰减增益进阈值。

2. **跨时刻白化级** $\bm W^{1/2}_{\mathrm{stk}}$：对零化后残差的堆叠协方差（含跨时刻相关）白化——正常校准段估计，保留现有收缩与岭正则配方。零化后条件数显著改善（去掉了沿 $\Phi$ 强相关的主扰动方向）。

3. **支路库级**：全能支路（满秩范数，保命题 3 的无盲区性）$\parallel$ 三条结构化匹配支路（各类白化签名子空间上的 GLR 统计量）。对支路 max 做一次分位校准（与 $T^{\max}$ 多尺度校准同构合并成"尺度 × 结构"二维支路族）。

需要证明的形式化结论：零化器存在性与核刻画（严格）；高斯新息下匹配支路的 GLR 等价与灵敏度增益（理想化模型下严格）；支路库 max 的 FAR 保持（给定块可交换性严格）；对未知故障不劣于纯白化的保底命题（严格）。全部只用正常数据装配与校准。

## 4. 突破二：输入与运行状态调度的动态阈值发生器

确定性部分从"标量球递推"升级为**在线辅助动力系统**（Ding 式阈值发生器的资格构造）：

1. **输入相关失配包络**：在正常验证集上按模糊区域估计条件包络 $\bar m_t=\eta_0(g)+\eta_u(g)\|u_t\|+\eta_{\Delta u}(g)\|\Delta u_t\|+\eta_\xi(g)\|\Delta\xi_t\|$——测得的输入瞬时幅值**在线**进入界。这是"随输入变化"的直接实现（估计为经验性质，进入定理时作为包络假设声明）。

2. **方向保留的集合传播**：把标量半径换成低阶 zonotope／椭球形状矩阵递推 $\mathcal P_{t+1}=A_{\omega,t}\mathcal P_t A_{\omega,t}^{\mathsf T}\oplus(\text{按 }B^u_t\text{、时滞链方向注入的生成元})$，隶属度调度的 $A_{\omega,t}$ 逐拍装配；阈值取传播集合在白化范数下的支撑函数——比 $\|W\|_2\times$ 球最坏方向紧一个量级级别的方向信息。在线成本用生成元降阶控制（zonotope order reduction，标准技术）。

3. **跨时刻保留**：堆叠窗口对"窗口内联合误差集合"整体传播（锚点误差生成元在窗口各块间共享），修复 1.2 第 3 条的结构丢弃。

4. **随机部分**：保留修正版推论 1 的可观测超额得分 conformal 校准，且现在校准的是**零化 + 集合传播之后**的剩余——确定性（输入/失配，集合传播）与概率性（噪声，conformal）按 skill 规则严格分账，保证形式为逐点 FAR。

5. **新增可检测性下界**：现设计只说"无普适下界"（诚实但空手）。升级为类条件结果：给定类 $i$ 签名算子的白化最小奇异值与阈值发生器输出，故障能量超过显式下界即保证检测（充分条件命题）——TFS 惯例明确要求这类结果，skill 参考模式也点名要它。

消融义务：新阈值 vs 旧标量球 vs 纯 conformal vs 静态阈值，在工况切换与大 $\Delta u$ 时段对比 FAR/MDR/延迟。

## 5. 突破三：三类故障的结构化隔离

1. **三类签名算子显式化**（第 2 节 $\bm F$ 族）：执行器沿用修正配对；传感器签名由编码器对 $y$ 历史槽位的 JVP 装配（直通块 + 滞后块 + 闭环经控制器的二次进入路径——后者在早期窗口内作为有界扰动处理，早期窗口规则从经验兜底升格为签名模型的显式假设）；过程类获得状态通道 Toeplitz 签名与激励条件。

2. **结构化滤波器组与关联矩阵**：对每类 $i$ 设计 $\bm V_i$，零化（可零化时）或最小化其余两类签名的增益、保持类 $i$ 增益，形成经典意义的 incidence structure；屏蔽编码器成为 $\bm V_{\mathrm s}$ 对编码器介导路径的实现方式，豁免检验成为"零化后统计量回落"的形式化判据。

3. **类间可分性定理**：白化度量下签名子空间两两主角 $\sin\theta_{\min}(\bm W\bm F_i,\bm W\bm F_j)\ge\gamma_{\min}$ 且扰动界小于裕度乘故障能量时，判决正确（充分条件定理）——把现有执行器通道裕度推广到**类级**。裕度不满足时的输出仍是 `Nonunique`／`unresolved`：七类诚实输出与拒识机制全部保留，但现在拒识条件由可分性定理的假设失效精确触发，不再是启发式补丁。

4. **判决逻辑**：分层判决保留（覆盖检查 → 传感器 → 执行器/过程），每个结构化统计量在正常校准段以与在线完全相同流水线校准（保留现设计已钉死的白化一致性与校准纪律）。命题 4 的不可辨识边界原样保留——它与新框架相容且是诚实边界。

## 7. 对抗性审查方案（三轮）
